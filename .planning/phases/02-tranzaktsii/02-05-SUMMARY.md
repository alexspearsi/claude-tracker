## Deviations from Plan

### Auto-fixed Issues

**1. [Rule 3 - Blocking] Восстановлено окружение сборки в этом worktree (Prisma-клиент, node_modules)**
- **Found during:** Задача 3, `npm run build`
- **Issue:** У этого ephemeral worktree нет собственного `apps/api/.env` и сгенерированного
  Prisma-клиента (тот же средовой пробел, что уже документирован в `02-03-SUMMARY.md`/`02-04-SUMMARY.md`),
  а также нет собственного `node_modules` ни на одном уровне — этот факт ранее считался безобидным
  (`typecheck`/`lint`/`prisma generate` проходили за счёт Node-резолюции модулей, поднимающейся мимо
  worktree к `node_modules` основного чекаута тремя каталогами выше). `npm run build` вскрыл, что
  это не так для `next build` (Turbopack): он детектирует workspace root по ближайшему lock-файлу
  (сам worktree содержит собственный `package-lock.json`, гит-трекнутый файл) и **отказывается**
  резолвить модули выше этой границы даже при наличии `node_modules` дальше по дереву каталогов —
  сборка падала с `Could not find the Next.js package (next/package.json)`.
- **Fix:** `apps/api/.env` не создавался (секрет-файл, `DATABASE_URL` передан прямой переменной
  окружения в команде — так `prisma generate` и `next build`/`nest build` не читают `.env` вовсе);
  Prisma-клиент сгенерирован (`npx prisma generate` с `DATABASE_URL` в команде, тот же общий docker
  Postgres на 5433, что и в предыдущих планах фазы); для `node_modules` — после неудачной попытки
  создать символическую ссылку на `node_modules` основного чекаута (`ln -s` в этой Windows-среде
  тихо создал полную рекурсивную копию вместо ссылки — обнаружено и удалено, `rm -rf`, не symlink,
  реальная директория с 561 top-level пакетом) выполнен обычный `npm install --prefer-offline` в
  корне worktree — создал собственный `node_modules` с корректными npm-workspaces symlink'ами
  (включая `@expense/shared` → локальный `packages/shared` этого worktree, а не основного чекаута).
- **Files modified:** нет отслеживаемых git-файлов — `apps/api/.env` не создавался вовсе,
  `node_modules` в `.gitignore`, `apps/api/src/generated/prisma/**` тоже игнорируется. Сборка также
  перегенерировала `apps/web/next-env.d.ts` (автогенерируемый файл, путь `.next/types` вместо
  `.next/dev/types`) — откачен `git checkout --` сразу после сборки как шум, не относящийся к задаче.
- **Verification:** `npm run build` из корня — код выхода 0, `/expenses` помечен `ƒ` (Dynamic) в
  таблице маршрутов. `git status --short` после всех действий показывает только ожидаемые изменения
  документации — ни одного случайного изменения кода.

### Найденный и исправленный в процессе баг (TXN-06)

«Все»: Radix `Select` не сбрасывал визуальное значение триггера при переходе `value` с реальной

`apps/web/src/widgets/expenses-list/ui/transaction-filters.tsx`, уже закоммичено в
`feature/transactions-crud`. Подробности — `02-04-SUMMARY.md`, раздел «Issues Encountered».
