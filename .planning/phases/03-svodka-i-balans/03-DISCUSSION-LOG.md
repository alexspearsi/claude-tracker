## Визуализация баланс/доходы/расходы

| Option | Description | Selected |
|--------|-------------|----------|
| Три компактные карточки в одной Card | Консистентно с существующими Card-виджетами | ✓ (recommended) |
| Текстовый абзац с числами | Менее сканируемо, не соответствует «одним взглядом» из цели фазы | |
| Три отдельные Card | Избыточная фрагментация для трёх связанных чисел | |

**Выбор:** Три блока (Баланс/Доходы/Расходы) внутри одной `Card`, цвет дохода/расхода — существующая конвенция `TransactionAmount` (emerald/destructive), баланс — нейтральный (факт, не оценка).
**Notes:** `formatMoney` переиспользуется без изменений, второй форматтер не пишется.

## Таблица разбивки по категориям

| Option | Description | Selected |
|--------|-------------|----------|
| Одна объединённая таблица | Соответствует буквальной формулировке SUM-02 («таблицу», ед. число); API уже отдаёт единый отсортированный массив | ✓ (recommended) |
| Две отдельные таблицы (доход/расход) | Не запрошено требованием, доп. сложность без обоснования | |

**Выбор:** Одна таблица, порядок строк — как отдаёт api (`byCategory`, уже отсортирован по убыванию `total`), различение дохода/расхода — через `CategoryDot` + знаковую сумму, без отдельной колонки «Тип».
**Notes:** Reversibility: reversible — разделение на две таблицы позже локально меняет один компонент, серверный контракт не тронут.
