## Алгоритм

1. Прочитать целевой файл ($0)
2. Проверить наличие Jest и @nestjs/testing в package.json
3. Если нет — установить необходимые зависимости
4. Определить все публичные методы и их зависимости
5. Для каждого метода сформировать тест-кейсы:
   - Happy path (успешное выполнение)
   - Edge cases (граничные значения, пустые данные)
   - Error cases (ожидаемые исключения)
6. Замокать все зависимости через jest.fn()
7. Создать файл [name].spec.ts рядом с тестируемым файлом
8. Запустить тесты: npm run test -- [имя файла]
9. Если тесты упали — исправить
