# Создание PR по аргументам

Аргументы вызова: `<заголовок PR> [base-branch]` (заголовок — всё, кроме последнего слова,
если оно похоже на имя ветки; при сомнении в разборе — переспроси). `base-branch` —
опциональный, по умолчанию `main`/`master` (смотри, какая ветка в репозитории дефолтная).
PR всегда создаётся из **текущей** ветки (`git branch --show-current`) — своё имя ветки
аргументом не передаётся. Если заголовок не передан — спроси его у пользователя, не
придумывай сам.

Правила веток, коммитов и оформления PR — по скиллу `commit`
(`.claude/skills/commit/SKILL.md`), обращайся к нему за деталями GitHub Flow и
Conventional Commits. Этот скилл — только про сам вызов `gh pr create`.

## Шаги

1. **Проверь состояние репозитория.** `git status` — если есть незакоммиченные изменения,
   спроси пользователя, коммитить их перед созданием PR или нет (не коммить и не отбрасывай
   молча).

2. **Определи base-ветку.** Если аргумент `base-branch` передан — используй его. Если нет —
   определи дефолтную ветку репозитория (`git remote show origin` или
   `gh repo view --json defaultBranchRef`) и используй её.

3. **Запушь текущую ветку**, если она ещё не на origin или есть новые коммиты:
   `git push -u origin <текущая-ветка>`.

4. **Собери описание PR перед вызовом `gh pr create`.** Обязательно посмотри
   `git diff <base-branch>...HEAD` и `git log <base-branch>..HEAD`, а не только последний
   коммит — тело PR должно перечислять реализованное по всей ветке. Формат тела:
   ```
   ## Summary
   - ...

   ## Test plan
   - [ ] ...
   ```

5. **Создай PR** переданным заголовком:
   ```bash
   gh pr create --title "<заголовок>" --base <base-branch> --head <текущая-ветка> --body "$(cat <<'EOF'
   ## Summary
   - ...

   ## Test plan
   - [ ] ...
   EOF
   )"
   ```

6. **Верни пользователю ссылку на PR**, которую выводит `gh pr create`.

## Важно

- Не пушь force и не переписывай историю без явной просьбы.
- Если `gh` не авторизован (`gh auth status` падает) — сообщи пользователю и предложи
  выполнить `gh auth login` самостоятельно (через `! gh auth login` в чате), не пытайся
  логиниться сам.
